kibaco sync（Chrome 拡張機能と iPhone のウィジェット）　2026年10月19日 制定

kibaco sync は、開発者本人が自分の授業の課題と資料を整理するためだけに使う個人用のツールです。一般には配布していません。

使う Google のデータと目的

Google ドライブこのツールが作ったフォルダとファイルだけを読み書きします（授業の資料とまとめ文書の保存）。ほかのファイルには触れません。
Google ToDo課題の締切をリストに登録し、完了の状態を読みます。iPhone のウィジェットは ToDo を読むだけです。
Google カレンダーこのツールが作った専用のカレンダーだけを読み書きします（締切のまとめの予定）。ほかのカレンダーには触れません。

データの置き場所

  • 読み書きしたデータは、利用者本人の Google アカウントと、本人の PC（Chrome の拡張機能の保存領域）・iPhone（Scriptable のキーチェーンと書類フォルダ）にだけ置きます。
  • 開発者が運営するサーバーはありません。データを第三者に送ったり、販売したり、広告に使ったりしません。
  • 例外として、利用者本人が自分の Gemini API キーを設定した場合に限り、まとめ文書（授業のお知らせ・課題・資料の要約）の文字を、そのキーで Google の Gemini API に送ります。質問に答えさせるためです。
  • Google API から受け取ったデータの利用は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従います。

許可の取り消し

Google アカウントの「セキュリティ」→「サードパーティのアプリとサービス」から、このツールへのアクセスをいつでも取り消せます。拡張機能を削除し、ウィジェットで「設定をすべて消す」を選ぶと、PC と iPhone に残った情報も消えます。
